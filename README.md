# Customer Churn Analysis Dashboard

## Project Overview
This project focuses on analyzing customer churn patterns in a telecom company using Power BI. The dashboard helps identify factors influencing customer retention and customer churn behavior.

## Objective
The main objective of this project is to:
- Analyze customer churn trends
- Identify high-risk customer groups
- Understand factors affecting customer retention
- Provide business insights through interactive visualizations

## Tools & Technologies Used
- Power BI
- DAX
- Excel / CSV Dataset

## Dashboard Features
- Total Customers KPI
- Customer Churn KPI
- Churn Rate Analysis
- Revenue / Total Charges Analysis
- Churn by Contract Type
- Churn by Internet Service
- Churn by Tech Support
- Tenure Analysis
- Interactive Filters & Slicers

## Key Insights
- Customers with month-to-month contracts show higher churn rates.
- Customers without tech support are more likely to churn.
- Fiber optic internet users have comparatively higher churn.
- Short-tenure customers contribute significantly to overall churn.
